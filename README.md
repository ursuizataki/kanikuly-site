# Сайт студии «Каникулы»

Одностраничный сайт студии ИИ-видео и анимации. Всё лежит в одном файле `index.html`: разметка, стили и скрипты. Сборка и установка не нужны.

## Как открыть

Откройте `index.html` двойным кликом в браузере. Чтобы заработало видео из папки `media/`, лучше запустить простой локальный сервер в этой папке:

```
python3 -m http.server 8000
```

и открыть http://localhost:8000.

## Что в папке

```
kanikuly-site/
├── index.html   сайт целиком
├── media/       сюда кладутся шоурил, ролики и кадры кейсов
├── README.md    этот файл
└── CLAUDE.md    контекст для Claude
```

## Структура страницы (сверху вниз)

1. **Заставка.** Слово «каникулы» раскрывается из буквы «к» слева направо и улетает в шапку. Пропускается кликом и не показывается, если в системе включено «уменьшить движение».
2. **Шапка** с логотипом и меню: работы, что делаем, связь.
3. **Шоурил** на всю ширину, сам запускается без звука и крутится по кругу. Пока нет файла `media/showreel.mp4`, вместо видео идёт анимированная заставка из обложек кейсов. Когда видео играет, появляется кнопка «со звуком».
4. **Заголовок** «миллионы смотрят до конца», слово «миллионы» выделено красным.
5. **Красная плашка с цифрами** «наши ролики набирают».
6. **Работы.** Горизонтальный аккордеон из 6 кейсов. Кейс раскрывается при наведении, на телефоне по нажатию.
7. **Что делаем.** Вкладки как в браузере, по одной на направление. Внутри вкладки описание, форматы и пайплайн «как работаем».
8. **Нас выбрали.** Список клиентов.
9. **Контакты:** почта с кнопкой «копировать», телеграм, город.
10. **Кнопка «связаться»** закреплена в правом нижнем углу и прячется, когда контакты уже на экране.

## Как править контент

Почти весь контент вынесен в два массива в `<script>` внизу `index.html`.

**`CASES`** — кейсы в разделе «работы». У каждого кейса есть поля:
- `chip`, `cover`, `bg`, `fg` — метка, слово-обложка и цвета;
- `client`, `format`, `title`, `task`, `did`, `res`, `resNote` — тексты кейса;
- `video` или `image` — путь к ролику или кадру, например `"media/leto.mp4"`; если поле заполнено, оно заменяет цветную обложку;
- `link` — ссылка на опубликованный ролик; пока поле пустое, кнопка «смотреть ролик» не показывается.

**`SERVICES`** — направления в разделе «что делаем»: `name`, `cover`, `bg`, `fg`, `desc`, `list` (форматы) и `steps`. Каждый этап записан как `[название, описание, плашка, true]`. Значение `true` в конце означает «утверждаете вы», такой этап подсвечивается.

Цвета и шрифты заданы токенами в `:root` в начале `<style>`. Там же лежит тёмная тема.

## Что ещё не сделано

- [ ] Положить настоящий шоурил в `media/showreel.mp4` (H.264, 1080p, 60–90 сек, желательно до 15 МБ).
- [ ] Добавить к каждому кейсу видео или кадр (`video`/`image`) и ссылку (`link`).
- [ ] Заменить логотип: в шапке сейчас временная перерисовка бегущих человечков, нужен оригинальный файл.
- [ ] Проверить цифры на красной плашке и в кейсах: каждая должна подтверждаться ссылкой.
- [ ] Проверить пайплайны направлений. Этапы ии-видео согласованы, остальные написаны по типовой схеме.
- [ ] Если нужна форма заявки, её придётся подключить к сервису приёма заявок (Formspree, Telegram-бот и т. п.), потому что своего бэкенда у сайта нет.
- [ ] Выложить сайт на хостинг, например Netlify, Vercel или GitHub Pages: страница статическая, достаточно загрузить папку.
